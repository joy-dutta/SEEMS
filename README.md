# SEEMS: Dynamic EV Charging Optimization using Stackelberg Game Theory
**Overview**

This repository presents a Stackelberg game-theoretic framework for optimizing Mobile Charging Vehicle (MCV) deployment alongside Fixed Charging Stations (FCSs) to dynamically manage electric vehicle (EV) charging demand. The model captures the hierarchical interaction between charging operators (leaders) and EV drivers (followers) to optimize MCV placement, pricing strategies, and service efficiency in urban environments.

**Key Features**

🚗 Game-Theoretic Optimization: Uses Stackelberg game modeling to balance operator profitability and user satisfaction.

🔄 Dynamic Deployment Strategy: Prioritizes high-demand locations using spatial-temporal ranking and real-time demand analysis.

📊 Multi-Objective Optimization: Maximizes profitability, charging resource utilization, and minimizes EV waiting time & unserved requests using Pareto optimization.

⚡ Scalable & Flexible: Designed to adapt to evolving EV charging patterns for both urban and suburban environments.

📈 Performance Validation: Simulations demonstrate reduced unserved EVs, improved station utilization, and enhanced service efficiency compared to an FCS-only setup.

**Technology Stack**

🧠 Game Theory + Optimization: Stackelberg game formulation & Pareto-based multi-objective optimization.

📊 Data Processing: Python (NumPy, Pandas, Scipy) for demand modeling and ranking.

⚙ Simulation & Evaluation: Simulated in Python using Open-Source libraries.


**Use Cases**

✔ Smart EV Charging Infrastructure for urban areas
✔ Dynamic Pricing & Resource Allocation for MCVs
✔ Demand-driven Energy Distribution for sustainable mobility
